# Polish pass plan (after the bug hunt)

Status: **approved 2026-09-30** (requested by the user: "after tests done polish everything with subagents").
Input: the web UI bug hunter's findings and UX observations, and the runtime/stress report. Correctness fixes were
done in the bug-fix round (CONTRACTS B.9); this pass is about usability, look and feel, accessibility and docs.

## Rules

- No new dependencies. Keep every existing label, button name, `data-testid` and `data-*` attribute that the e2e
  suite relies on (see the UI contract tables in `docs/plans/phase-{2..8}.md`); new UI gets new testids.
- At most one `role="alert"` per page (the page-alert slot). Works at 390 px (phone) and 1280 px (desktop).
- Each agent works in its own git worktree, based on current `main`, and owns a disjoint set of files (below).
